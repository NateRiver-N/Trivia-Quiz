# 🧠 Trivia-Quiz

A modern trivia game built with React, FastAPI, and MongoDB where players can test their knowledge, earn XP, climb leaderboards, and track their progress.

## 🚀 Features

* 🔐 JWT Authentication
* 🏠 Responsive Home Page
* 🎮 Match Lobby
* 📝 Multiple Choice Quiz System
* 🏆 Ranking Leaderboard
* 👤 User Profiles
* ⭐ XP & Ranking System
* 📱 Mobile Responsive UI
* 🌙 Modern Dark Theme

---

### Frontend

## ⚙️ Installation

### Clone Repository

```bash
https://github.com/NateRiver-N/Trivia-Quiz.git

### Frontend

```bash
cd frontend

npm install

npm run dev
```

### Backend

```bash
cd backend
requirements.txt not built yet backend is just started

pip install -r requirements.txt

if using any virtual environment
venv\Scripts\activate


uvicorn server:app --reload
```
