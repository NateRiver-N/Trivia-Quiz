# 🧠 Trivia-Quiz

A modern trivia game built with React, FastAPI, and MongoDB where players can test their knowledge, earn XP, climb leaderboards, and track their progress.

## 🚀 Features

* 🔐 JWT Authentication
* 🏠 Responsive Home Page
* 🎮 Match Lobby
* 📝 Multiple Choice Quiz System
* 🏆 Ranking Leaderboard
* 👤 User Profiles
* ⭐ XP & Ranking System
* 📱 Mobile Responsive UI
* 🌙 Modern Dark Theme

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/trivia-arena.git
```

### Frontend

```bash
cd frontend

npm install

npm run dev
```

### Backend

```bash
cd backend

pip install -r requirements.txt

uvicorn main:app --reload
```
